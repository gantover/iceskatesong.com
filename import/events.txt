# ISU result events the Import reads: one event index URL per line.
# Blank lines and lines starting with # are ignored.
#
# Scope: senior and junior ISU Championships, Grand Prix and Final, Junior Grand Prix
# and Final, Olympics and Youth Olympics, World Team Trophy, and other ISU-run events
# on results.isu.org (= isuresults.com). Challenger Series and other international
# competitions are left out: most of their results live on the organisers' sites.
#
# Adding a Season: once an event's results are online, add its index URL under a new
# "# YYYY–YY" header (~25 per Season). Since 2015–16 the host files events under
# results/seasonYYZZ/<code>/, e.g. results/season2627/gpfra2026/index.htm.
# Event codes: gp<nation><year>, jgp<nation><year>, gpf<year>, ec/fc/wc/wjc<year>,
# owg/wtt<year>. Codes and folders vary between Seasons: copy the URL the host serves.
#
# 2004–05 events come from an older results vendor: uppercase result filenames and no
# seasonYYZZ/ folder (some 2004–06 JGP indexes link SEG001.HTM where the host serves seg001.htm; the
# Import tries both). A few Japan-hosted events from 2017–18 to 2023–24 use another vendor's
# dataNNNN.htm pages instead of SEGnnn.htm (NHK Trophy 2017–2023, GP Final 2017, Worlds 2019
# and 2023, World Team Trophy 2019–2023, JGP Osaka 2023).
# Events with no results online are noted in a comment under their Season, never as URLs.
